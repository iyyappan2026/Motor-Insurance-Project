# Monarchy Motor Insurance Management System

## Project Overview
The Monarchy Motor Insurance Management System is a MySQL database project developed to automate the complete motor insurance process.

The project covers:

- Customer Management
- Vehicle Management
- Product Management
- Premium Calculation
- Quote Generation
- Payment Processing
- Policy Management
- Credit and Debit Notes
- Stored Procedures
- Functions
- Triggers
- Event Scheduler
- Transactions
- Indexes
- User Privileges (Grant & Revoke)

## Technologies Used

- MySQL

- SQL
- GitHub
